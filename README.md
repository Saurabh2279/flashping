# 💬 FlashPing — WhatsApp Without Saving Numbers

FlashPing is a lightweight, privacy-focused PWA (Progressive Web App) that allows you to send WhatsApp messages to any phone number without needing to save them to your contact list first.

![FlashPing Preview](https://via.placeholder.com/1200x600?text=FlashPing+Web+Application+Preview)

## ✨ Features

- **Instant Messaging**: Start chats by simply entering a phone number.
- **Global Support**: Integrated country picker with automatic dial codes.
- **Privacy First**: All data is stored locally in your browser. No backend, no tracking.
- **PWA Ready**: Installable on Android, iOS, and Desktop for a native experience.
- **Recent History**: Keep track of numbers you've messaged recently.
- **Contact Management**: Save frequently used numbers within the app.
- **Dark Mode**: Optimized for comfortable use day and night.
- **Custom Messages**: Pre-fill message text for quick sending.

## 🚀 Deployment

This project is ready to be deployed as a static site.

### Deploy to GitHub Pages
1. Create a new repository on GitHub.
2. Push this code to the repository.
3. Go to **Settings > Pages**.
4. Select the `main` branch as the source and click **Save**.
5. Your app will be live at `https://<username>.github.io/<repo-name>/`.

## 🛠️ Tech Stack

- **Frontend**: HTML5, Vanilla CSS3, JavaScript (ES6 Modules)
- **PWA**: Service Workers for offline support and manifest for installation.
- **Storage**: Browser LocalStorage for persistence.
