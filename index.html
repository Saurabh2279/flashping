    Privacy & Terms

    Privacy Policy

    Data Storage: All phone numbers, names, and messages are stored locally in your browser cache. We have no access to this data.

    CRITICAL WARNING: Clearing your browser cache, history, or website data will permanently delete all your recents and saved contacts. This action is irreversible.

    Analytics: We use anonymous, cookie-less analytics via Umami Analytics to track country-level traffic. No personal information, cookies, or IP addresses are stored or linked to you.

    Terms of Service

    Service: FlashPing uses WhatsApp's official Click to Chat feature. We do not host any messaging services.

    Non-Affiliation: This tool is NOT affiliated with, authorized, or endorsed by WhatsApp Inc. or Meta.

    Disclaimer: Use this tool at your own risk. We are not responsible for any misuse or consequences of messages sent via this tool.

    Install FlashPing

    Install FlashPing on your device for offline support, fast launch, and a native app experience.

    100% Safe: Installs securely as a Progressive Web App (PWA) directly via your browser. No harmful downloads (like .APK, .EXE, or .DMG installer files) are required, keeping your system completely safe. Learn more about PWA.
    Android Users

    For a proper standalone application, we highly recommend using Google Chrome or Samsung Internet.

    Other Browsers (like Brave or Firefox):
    • Tap browser menu (three dots) → select "Add to Home screen" or "Install".
    Windows & Desktop Users

    For a proper standalone application, we highly recommend using Google Chrome or Microsoft Edge.

    Other Browsers (like Brave or Opera):
    • Click the Install icon in the address bar, or menu (three lines/dots) → select "Install FlashPing".
    • *Note: Desktop Firefox does not natively support PWA installation.
    Apple Users
    iPhone & iPad (Safari required):
    1. Tap the Share button (square with arrow) at the bottom.
    2. Scroll down and tap Add to Home Screen.
    3. Tap Add in the top-right corner.
    Mac / macOS (Safari 17+):
    • Open Safari → click File menu → select Add to Dock...
